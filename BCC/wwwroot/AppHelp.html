1. Overview

The BCC Application is a web-based management system for the Bloemfontein Camera Club (BCC). It tracks monthly competition entries, scores, awards, member grading, and salon participation throughout the club's fiscal year (1 November – 31 October).

Key capabilities at a glance:

  • Display and manage monthly competition results (Pictorial, Nature, Set Subject)
  • Year-to-date scoring, star-level promotions, and Golden Honours / Galaxy tracking
  • Full salon (PSSA national/international) participation records per member
  • Member list management with CSV import from Ledelys
  • Admin tools: photo import/processing, data import, database backup/restore, Word-to-HTML conversion, and publishing to the live hosting server
The application runs on ASP.NET Core Blazor Server. All interactions update in real time without page reloads.

3. Awards (Results) /results

Displays all award-winning photos for a selected month, grouped by category and star level. Use the month selector at the top to navigate between months.

Categories

  • Pictorial – general creative photography
  • Nature – wildlife, flora, and natural landscapes
  • Set Subject – a prescribed theme announced per month

Award Indicators

A Winner badge marks the top scorer in a category/star group; a Club Winner badge marks the top overall club scorer.

4. Scores (Points) /points

Shows the year-to-date scoring dashboard for the current or selected year. Three columns are displayed side by side:

  • Club Points – cumulative competition scores per member
  • Set Subject Points – points earned specifically in the set-subject category
  • Salon Points – points from PSSA salon participation

Star Promotion Levels

Each column is segmented by star group (1★ to 5★, Golden Honours, Galaxy). A StarLevelTable at the bottom of the page shows the thresholds required for promotion (see Section 17: Scoring & Promotion).

Individual Member Scores

Click any member name to open their personal score history /pointsmember/{Data}, showing every monthly entry with colour-coded promotion status:

  • Green – on track for promotion
  • Red – at risk / behind target

6. Members List /masterview

Shows the full member roster with sortable columns: Name, Rating (star level), Title (honours), Email, and Mobile. A toggle lets you view paid members only or all members.

Importing Members from Ledelys

  1. Export the member CSV file from the Ledelys system.
  2. Click Import CSV on the Members List page.
  3. Select the exported .csv file in the file chooser dialog.
  4. The system maps and imports the member data automatically.

Export

Use the Export button to download the current member list to a CSV file for external use (mail merges, reports, etc.).

7. Honours /honours

Allows an administrator to assign or update a member's photographic title / honours designation (e.g. APSSA, FPSSA).

  1. Select the member from the dropdown list.
  2. The current honours title is displayed for reference.
  3. Type the new title in the input field.
  4. Click Save to apply the change.
Honours titles appear next to the member's name on the scoring and results pages.

8. Salon Administration /salonMasMain

The salon administration hub manages Salon Masters (the salon events themselves) and the participant scores for each event. Three views are available from the Salons menu:

ViewRoutePurpose
Salons Current/salonMasMainCurrent fiscal year's salons
Salons Previous/salonMasMain/prevPrevious fiscal year's salons
Import Salons/salonMasMain/importlistImport a PSSA salon list from CSV

Creating a New Salon Master

  1. Click New on the salon list.
  2. Enter the salon Name, Date, and check International if applicable.
  3. Click Save.

Adding Participant Scores

  1. Select a salon from the list to open its detail view.
  2. Click Add Participant.
  3. Choose the member, then fill in Acceptances, COM, Points, Judge, and Award fields.
  4. Click Save.

Importing from PSSA CSV

  1. Download the PSSA salon result PDF from the PSSA website.
  2. Convert the PDF to a .csv file.
  3. Navigate to Salons → Import Salons.
  4. Select the .csv file — the system parses and imports all results.
The import sets the Imported flag on the Salon Master automatically.

9. Admin: Images Process /admin/images-import

Automates the full pipeline from raw zip archives of club photos to web-ready images on both the local server and Absolute Hosting. The pipeline runs six sequential steps:

  1. Unzip selected .zip archives to D:\BKK\Inbox\Club\Photos\{Date}\.
  2. Copy and rename photos to a standardised 7-digit numeric filename in the Temp\ sub-folder.
  3. Generate web-optimised images (1365 × 768 px) and save to D:\BKK\Inbox\Club\Photos\WEB\.
  4. Copy web images to the local website folder wwwroot\ClubPhotos\{Date}\.
  5. Create a zip of the web images in ..\Downloads\ZippedExport\.
  6. Upload the zip to Absolute Hosting via the API to wwwroot\Import\{yyyy.mm}.zip.
Ensure VPN is connected before starting if the upload step (step 6) is required to reach Absolute Hosting.

Progress is displayed in the modal progress bar during each stage.

10. Admin: Import Club Data /admin/club-import

Imports monthly competition scores from a Scoresheet.csv or Results.csv file. In October (year-end) a special YearEnd import mode is available.

Typical Monthly Import

  1. Place the scoresheet CSV in the Import staging folder (wwwroot/Import/).
  2. Navigate to Admin → Import Club.
  3. Select the correct month if not already pre-selected.
  4. Click Import — results appear on the page as they load.

Year-End Import (October)

When the active month is October, an additional YearEnd option appears. This finalises the fiscal year, locks scores, and prepares the database for the new November start.

Run the YearEnd import only once at the end of October. It cannot be easily reversed — take a database backup first.

11. Admin: Word to HTML /worddoc

Converts a Microsoft Word .docx document to an HTML file and saves it automatically to wwwroot/Html/, making it immediately accessible from the Info menu.

  1. Navigate to Admin → Word.
  2. Click the file input and select a .docx file.
  3. The conversion runs server-side; the resulting HTML is saved with the same base name as the Word document.
  4. The new page appears automatically in the Info menu on the next menu refresh.
Images embedded in the Word document are extracted and saved alongside the HTML file.

12. Admin: Upload to AbsHosting /upload-to-abs

Uploads HTML content files or photo ZIP archives directly to the Absolute Hosting server using a token-authenticated API.

  • .html files – replaces the corresponding Info page on the live site
  • .zip files – bulk image packages placed in the live Import/ folder
  1. Navigate to Admin → Upload to AbsHosting.
  2. Select the file(s) to upload.
  3. Click Upload — progress is shown per file.
Requires a valid API token configured in appsettings.json and an active VPN connection to Absolute Hosting if uploading from outside the hosted environment.

13. Admin: Backup & Restore DB

Backup /admin/backup

Creates a full SQL Server backup of the active database and saves it to the local wwwroot/Backup/ folder.

  1. Navigate to Admin → Backup DB.
  2. Enter a filename (or accept the date-stamped default).
  3. Click Backup — the backup file appears in the list when complete.

Restore /admin/restore

Restores the database from a previously created backup file.

  1. Navigate to Admin → Restore DB.
  2. Choose the backup file from the dropdown list.
  3. Click Restore and confirm the warning dialog.
Restore overwrites all current data. Always take a fresh backup before restoring to a different point in time.

14. Admin: Excel Export /admin/excel

Exports all monthly competition records (Monthlies) for the selected year to an Excel file. Files are saved to:

D:\BKK\ARCHIVES\Ou punte rekords\{Year}\

  1. Navigate to Admin → Excel.
  2. Verify the year shown is correct.
  3. Click Export — the file is created and its path is confirmed on screen.

15. Admin: Delete Month /admin/deletemonth

Removes all competition records for the last imported month from the database. Photo image files on disk are not deleted.

This operation is destructive and cannot be undone from within the application. Always perform a database backup before deleting a month.
  1. Navigate to Admin → Delete Month.
  2. Confirm the month shown is the one to be removed.
  3. Click Delete and confirm the warning dialog.

16. Database Switching

The application can connect to two database environments. The active database key is shown in red at the left of the menu bar.

OptionKeyUse Case
Local XPS / ROG Development and data-entry on the local machine.
Absolute Hosting Abshost Live production database on the hosted server. Requires VPN access.

Navigate to DB → Local or DB → Absolute Hosting to switch. The page reloads and re-connects automatically.

Changes made on Local are not automatically synchronised to Absolute Hosting. Use the Backup / Restore workflow or the Upload tool to push data to the live server.

The club uses a star-based grading system. Members are promoted when they meet the cumulative thresholds for their current star group.

Important Rules

  • Club points and gold/merit awards earned within a star group do not carry over to the next group — only salon points accumulate across promotions.
  • The club fiscal year runs from 1 November to 31 October.
  • Only paid members are included in active scoring tables.

18. File & Naming Conventions

Photo Filenames

Web-optimised photos are renamed to a standardised 7-digit numeric ID (e.g. 0012345.jpg). The original filename from the member is used to derive the category, star group, and date during the Images Process pipeline.

Import Folders

PathContents
wwwroot/Import/Staging area for incoming CSV and ZIP files
wwwroot/Backup/SQL Server database backup files
wwwroot/html/Static HTML content files served via the Info menu
wwwroot/ClubPhotos/{Date}/Web-ready competition photos per month
D:\BKK\Inbox\Club\Photos\Raw photo working directory (local machine)
D:\BKK\ARCHIVES\Long-term Excel archive exports

Info / HTML Content Files

Any .html file placed in wwwroot/html/ automatically becomes an item in the Info menu. The menu entry label is the filename without the .html extension. Files are served via the route /info/{filename}.
