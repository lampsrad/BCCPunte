    BCCPunte — Menu Help

    Every item in the gold menubar (Menu.razor / Menu.razor.cs). Click a control name (blue, like the TOC) to swap its Effect for the full code flow — every method called, in order. Turn on Edit page (top right), then click any highlighted text to change it; edits are saved to Help-flows.json and restored on reload. After editing, run Help_Merge (this page toolbar, or hover Admin → Help for the flyout) to bake changes into Help.html / Help-flows.js and clear the JSON overlay — same as Project Viewer. Fiscal year: 1 November – 31 October.

    Status strip

    ControlEffect / Code flow (click control)
    Status strip · left
    Red label showing gData.connectionKey — which SQL connection string is active (Local, machine key, or Abshost). Tooltip: “The Database in use”. Not clickable; changes when you use DB → Local or Absolute Hosting.
    Status strip · centre
    Shows the current competition month as full month name + year from state.DatePhoto (via state.Title). Updates whenever the menu state event fires after a date change on Awards / Scores / Salons.
    Status strip · home · /
    Home link. Index loads last import dates from Datum and shows category winners (Winner / Club_Winner) for the newest photos folder that contains a Temp\ subfolder.

    Members

    ControlEffect / Code flow (click control)
    Members → Awards · /results
    Monthly competition results. DateChange month picker drives which month is shown. Displays a Winners table plus tables for each category / star group (nature, pictorial, set subject, phone).
    Members → Scores · /points
    Year-to-date scoring dashboard for the club fiscal year. Top-ten leaderboards (Club Points, Set Subject, Salons), promotions list, and star-level grids (1★ through Galaxy) with red threshold cells. Row button All opens a member’s full monthly history.
    Members → Salons · /salons
    Member-facing salon participation view (not admin CRUD). Lists salon results for the selected scope: month buttons, plus PSY (PSSA year), BCY (BCC year), NEW. Columns: SalonName (alias preferred), Name, Coms, Acc, Judge, Points, Award.
    Members → InterClub · no page
    Does not open a page. Exports high-scoring photos from the last 12 months into export folders for inter-club selection: Exports\Juniors (rating < 4), Exports\Seniors (rating > 3 and score > 11), Exports\Seniors_11 (score = 11). Files named {Lastname} {Firstname} {Title} [{Score}].jpg.
    Members → Members List · /masterview
    Full master roster. Buttons: Update (import *Ledelys*.csv from Downloads — sets Paid/email/mobile/bday), Paid / All filters, List (write paid members to Downloads\Members.csv). Name column header sorts the table.

    Honours

    ControlEffect / Code flow (click control)
    Honours → Honours · /honours
    Adjust a member’s PSSA / club honours title. Page loads masters that have an IdVault, focuses the dropdown. Choose member (shows previous title), type new title (e.g. APSSA, FPSSA), Submit appends it to Master.Title (uppercased). If title is APSSA or FPSSA and points thresholds are met, promotes the member (5★ + Pp≥150 + Salp≥200 + APSSA → Golden Honours; 6★ + Pp≥150 + Salp≥400 + FPSSA → Galaxy), clears promotion accumulators, saves Master + Monthly, navigates home. Cancel returns home without saving.

    Salons (admin)

    ControlEffect / Code flow (click control)
    Salons → Salons Current · /salonMasMain
    Salon administration for the current period. Index of salon masters: Create, Edit, Show participants, Delete (only if no child rows). Click salon name to import that event’s PSSA CSV (if not already imported).
    Salons → Salons Previous · /salonMasMain/prev
    Same salon-admin UI as Salons Current, scoped to the previous period’s salon masters.
    Salons → Import Salons · /salonMasMain/importlist
    Bulk-import the year’s salon list. Tooltip: get PDF from PSSA website, convert to CSV, then import. File picker reads club, salon name, and date (dd-MM-yyyy) and creates SalonMaster rows.

    Info documents

    ControlEffect / Code flow (click control)
    Info → {each wwwroot/Html/*.html} · /info/{name}
    The Info submenu is built at menu startup: every .html file in wwwroot/Html/ becomes a link. Clicking a name opens that document in Info.razor. New documents appear after Admin → Word converts a .docx into wwwroot/Html/. Documents include About, Grading, Judging, Program, PSSA, Constitution, etc.

    Admin

    ControlEffect / Code flow (click control)
    Admin → Images Process · /admin/images-import
    Full photo pipeline for the monthly club competition images (does not import scores). Unzip Photovault zips → rename by 7-digit IntRef → generate 1365×768 previews → zip + copy to local ClubPhotos → upload zip to Absolute Hosting.
    Admin → Import Club · /admin/club-import
    Main monthly data import (“Hoof Ingangsroete”). Imports Scoresheet and/or Results CSVs from the Import folder (or year-end path when last import month is October). Creates/updates masters and photos, aggregates monthlies, stores dates, runs Promotion_Due. May pause for interactive photo-limit chooser (max 3 non-S + 2 S per member).
    Admin → Import Salon · /salonMasMain
    Opens the salon admin shell (same as Salons Current). Import a single salon by clicking its name on the index (CSV must contain the salon name token).
    Admin → Word · /worddoc
    Convert a Microsoft Word .docx (max 25 MB) to HTML and save under wwwroot/Html/ so it appears under Info. Program (Afr)/(Eng) get Venue + Program header images. After conversion, navigates to the Info page.
    Admin → Upload to AbsHosting · /upload-to-abs
    Upload chosen .html files or image zips to Absolute Hosting’s wwwroot via the club API.
    Admin → Backup DB · /admin/backup
    Opens backup file picker (type a new name or choose existing .bak). Runs SQL Server backup via repository.
    Admin → Restore DB · /admin/restore
    Restores the database from a .bak file. If Downloads\bcc.bak exists, moves it into the backup folder first, then shows the picker.
    Admin → Excel · /admin/excel
    Archives Monthly score snapshots as CSV files under D:\BKK\ARCHIVES\Ou punte rekords\{year}\, walking every month from November 2013 to today.
    Admin → Delete Month · /admin/deletemonth
    Deletes last-imported month data from the database so you can re-import: Photos, Monthlies, Salons, SalonMasters. Disk images are left intact. Restores master ratings from remaining monthlies and updates Datum dates.
    Admin → Help · /Help.html · new tab
    Opens this static help page in a new browser tab. Hover (or focus) the Help item to open a flyout with Help_Merge — same layout as Project Viewer.
    Admin → Help → flyout · also on this page toolbar
    Flyout under Help — merges Help-flows.json edits into Help.html (effects + editable content) and syncs flow steps into Help-flows.js, then clears the JSON overlay. Use after editing Help so source files (and git) hold the permanent text. Creates .bak backups first.

    DB & Close

    ControlEffect / Code flow (click control)
    DB → Local
    Switches the app to the local SQL connection. Writes the hit counter back to the local database. The status strip DB key updates to Local.
    DB → Absolute Hosting
    Switches to the Absolute Hosting connection string. Loads the remote hit counter into gData.HitCount. Typically requires VPN for production database access.
    Close · production only
    Visible only when env.IsProduction(). Shuts down the launched browser process and stops the host application.
